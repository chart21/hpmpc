# HPMPC Benchmark Results — H100 (Single Machine, 2-Party)

**Hardware:** 8× NVIDIA H100 80GB HBM3  
**Protocol:** PROTOCOL=4 (ABY2 / Cheetah 2PC)  
**Model:** ResNet50 Cheetah (FUNCTION_IDENTIFIER=87), single batch, ImageNet input  
**Setting:** Both parties on the same machine; P0 assigned GPUs 0–6, P1 assigned GPU 7  
**Date:** June 2026

---

## Results (Party 0 / P0)

### Preprocessing

| Test | CHEETAH_GPU | USE_CUDA_GEMM | Total Pre Time | Comm Sent PRE |
|------|------------|---------------|---------------|---------------|
| 1 — Full CPU | 0 | 0 | 45.93s | 998 MB |
| 2 — GPU pre, CPU GEMM | 1 | 0 | 35.27s | 164 MB |
| 3 — GPU pre, GPU GEMM=2 | 1 | 2 | 34.22s | 164 MB |
| 4 — GPU pre, GEMM=0 | 1 | 0 | 35.27s | 164 MB |

> Tests 2 and 4 use the same preprocessing configuration — the difference is USE_CUDA_GEMM only affects the online phase.

### Online Phase

| Test | CONV2D Online | ACTIVATION Online |
|------|--------------|------------------|
| 1 — Full CPU | **985 ms** | 41,945 ms |
| 2 — GPU pre, CPU GEMM | 2,219 ms | 40,601 ms |
| 3 — GPU pre, GPU GEMM=2 | 4,101 ms | 40,225 ms |
| 4 — GPU pre, GEMM=0 (explicit) | **986 ms** | 42,019 ms |

---

## Key Observations

| Finding | Detail |
|---------|--------|
| **GPU preprocessing is 24% faster** | 35.3s vs 45.9s — TROY HE on GPU accelerates triple generation |
| **GPU preprocessing sends 6× less data** | 164 MB vs 998 MB — more efficient ring parameters in TROY |
| **USE_CUDA_GEMM=2 slows online CONV2D** | 4,101 ms vs 985 ms — H100 kernel launch overhead dominates for single-batch small matrices |
| **CPU GEMM is optimal for online** | Tests 1 and 4 both achieve ~986 ms CONV2D — single-batch ResNet50 is too small to saturate H100 GEMM |
| **ACTIVATION is GPU-independent** | ~40–42s across all tests — dominated by ReLU communication round-trips |
| **Best configuration** | `CHEETAH_GPU=1 USE_CUDA_GEMM=0` — GPU for preprocessing, CPU for online GEMM |

---

## Notes

- All runs: single machine, same-machine 2-party, SKIP_PRE=0 (full preprocessing + online)
- GPU assignment: P0 → `CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6`, P1 → `CUDA_VISIBLE_DEVICES=7`
- Logs saved in `hpmpc/logs/` (cpu_full_run.log, gpu_full_run.log, gpu_gemm_run.log, gpu_nogemm_run.log)
- ACTIVATION time (~40s) is dominated by the ReLU/comparison protocol communication and is not significantly affected by GPU acceleration in this configuration
